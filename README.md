# SQL 반례 실험실

**반례 데이터로 SQL 풀이의 오류를 이해하는 학습용 웹 앱입니다.**

샘플에서는 맞아 보이던 SQL도 중복 행, NULL, 주문이 없는 고객 같은 조건에서는 다른 결과를 낼 수 있습니다. 작은 입력 데이터와 내 결과·기대 결과를 나란히 보면서, 어떤 행을 놓쳤고 왜 결과가 달라지는지 확인합니다.

## 누구를 위한 서비스인가요?

SELECT와 JOIN의 기본 문법은 알지만, 샘플을 통과한 쿼리가 다른 데이터에서 틀리는 이유를 이해하고 싶은 학습자를 위한 실습 도구입니다.

## 이렇게 학습합니다

1. 자연어로 작성된 문제 목표와 출력 조건을 읽습니다.
2. 입력 데이터를 **표 보기 / 텍스트 보기**로 살펴보고 SQL을 작성합니다.
3. **실행**으로 현재 샘플의 결과를 확인합니다.
4. **정답 확인**으로 준비된 테스트 데이터를 검사합니다.
5. 실패하면 첫 실패 사례의 입력 데이터, 내 결과와 기대 결과, 누락·추가·중복 횟수 차이를 비교합니다.
6. 단계별 힌트와 고정 해설을 읽거나 **다른 예시로 이해하기**에서 별도 학습 예시를 실험한 뒤 수정합니다. 정답 쿼리는 **정답 SQL 보기**를 직접 열 때 확인합니다.

## 제공하는 기능

- **초급·중급·고급 각 10문제, 총 30문제**: 조건식, NULL, 집계, JOIN, 순위·누적 계산과 재귀 등 서로 다른 개념을 다룹니다. 선행 문제 잠금은 없습니다.
- **문제별 5개 검사 사례**: 첫 실패 데이터와 실제 결과 차이를 보여줍니다. 행 순서는 무시하고 중복 개수와 열 위치는 보존합니다.
- **표와 텍스트 두 가지 데이터 보기**: 스키마·자료형·NULL 허용 여부를 확인하고 원본 CREATE/INSERT SQL도 펼쳐 볼 수 있습니다.
- **검증된 학습 예시 30개**: 문제마다 별도 작은 데이터, 개념 예시의 실행 결과와 고정 설명을 제공합니다. 내 SQL을 예시 데이터에서 실행해도 본문 풀이와 채점 결과는 유지됩니다.
- **브라우저 SQLite**: Web Worker에서 SQL을 실행합니다. 기본 실습·채점·해설·예시는 별도 백엔드나 DB 서버 없이 동작합니다.
- PC 중심 화면과 작은 화면의 읽기·짧은 수정, 데이터 영역 내부 스크롤을 지원합니다.

## 알아둘 범위

준비된 사례를 모두 통과했다는 것은 **해당 검사 사례에서 결과가 일치했다는 뜻**이며, 모든 데이터에서 정답이라는 증명은 아닙니다. 범용 SQL 동치 검증기나 임의 업무 데이터 검증 서비스가 아닙니다. 최초 난이도는 교육적 추정입니다.

학습용 앱이므로 기준 쿼리는 클라이언트에 포함됩니다. 입력 데이터 편집·로그인·동기화는 제공하지 않습니다. 읽기 전용 단일 SELECT와 지원하는 WITH SELECT를 실행하며 SQL 크기·결과 크기·실행 시간을 제한합니다.

**공개판에는 AI 질문 기능을 제공하지 않습니다.** 로컬 Ollama를 사용한 실험 코드는 개발용 opt-in 경로에 보존했습니다. 실제 검증에서 설명 오류가 남았으며 SQL 채점과 고정 해설을 AI에 맡기지 않습니다.

## 로컬에서 시작하기

Node.js 22 이상에서 이 폴더를 열고 실행합니다.

```sh
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:5174 를 엽니다. 기본 실행에서는 AI와 백엔드가 필요하지 않습니다.

```sh
npm test
npm run build
npm run preview
```

정적 빌드 결과는 `dist/`, preview 주소는 http://127.0.0.1:4173 입니다. 아직 공개 서비스 주소는 없습니다.
